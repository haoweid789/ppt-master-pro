# 设计技巧库(ppt-master-pro / references)

14 个方向的精选技巧,源自旁门左道PPT / 秋叶PPT / 珞珈PPT 等平台技法整理(294 条去重库的提炼版)+ presentations:pptx 规范。
使用时机:Phase 2 定设计规范时按需查阅对应方向。

---

## 一、版式(9 式经典公式)

1. **上下结构**:标题带(文字,非色条)+ 下方内容区——最稳的默认
2. **左右分割**:文字一侧、图/表一侧,黄金比 0.618 分割
3. **三分网格**:纵向三栏,信息分级排布,栏间距一致
4. **中心对称**:焦点居中,四周留白——只用于金句/大数字页
5. **对角线构图**:元素沿对角线排布,制造动感——封面/过渡页
6. **满版出血**:图片铺满全幅+深色遮罩+文字——章节页/情绪页
7. **卡片行**:一行并排 2–4 张同构卡片——团队/特性对等项(≤1/5 内容页)
8. **时间轴**:水平轴+交替上下节点——里程碑/路线图
9. **目录导航条**:agenda 页高亮当前章节,翻页重复锚点——长 deck 定位感

## 二、色彩

- **70-25-5 法则**:主色约 70% 面积权重,辅助色 25%,强调色 5%
- 三角色模型:BACKGROUND(60–70%)→ PRIMARY → ACCENT,全 deck 复用同一组常量
- 取色从主题来:行业色(金融蓝绿/医疗青白/餐饮暖橙)、品牌色、地域/意象色
- 需要更多区分度→用主色的深浅变体(tints/shades),不引入新色相
- 对比检查:正文与背景对比度 ≥ 4.5:1;投影场景拉高对比
- 禁:彩虹配色、每页换色、低饱和灰字配灰底、默认奶油底

## 三、字体排印

- 层级靠**字号+字重**,不靠换字体;最多 2 字族
- 画布 13.33×7.5":封面 44–72pt,页标题 32–36pt+,正文 20–24pt,注释/来源 ≥12pt
- 行长:每行 30–40 个西文字符或 15–22 个汉字;行距 1.15–1.3
- 中文深浅字重对比做层级:Regular 正文 + Bold 标题;禁 Light/Thin 投影发糊
- 对齐只有两种:左对齐(正文)、居中(标题/金句);两端对齐慎用(中西混排会拉出大空隙)
- CJK 文本框比同长度西文宽 ~15%,防中段折行

## 四、图片处理

- 文字压图必加 60–80% 深色遮罩;或改分栏布局,图归图、文归文
- 比例不符裁切(cover),永不拉伸;人物图视线朝向文字侧
- 灰度测试:黑白打印后图上每个字仍可读才算合格
- 图区不是空白区:图发暗先调遮罩/换图,不在图上叠装饰
- 搜索关键词向"具体场景"取,不向"抽象概念"取(要"仓库叉车夜景"不要"物流概念图")

## 五、图表

- 选择顺序:总量对比→柱状;趋势→折线;占比(≤5 项)→环形/饼;相关性→散点;禁止 3D/渐变图表
- 单系列不配图例,直接数值标签;多系列图例置底
- 堆叠图数据标签只用 ctr/inBase/inEnd(用 outEnd 会触发 PowerPoint 修复弹窗)
- 高亮单根柱:per-point 颜色(目标柱用 ACCENT,其余用 PRIMARY 淡化)
- 网格线只留值轴、细线淡色;去掉一切 chart junk
- 每图配来源行(10–12pt muted);估算值标"示意/est.";坐标轴有单位

## 六、数据强调

- 大数字法:60–72pt 主数字 + 14pt 小标签,一页最多 1–3 个大数字
- 对比法:before/after 双柱或双行,"3.1% → 5.8%" 箭头式
- 表格只用于精确查阅(>9 行建议拆页或转图表);隔行条纹,表头主色底白字
- 单位紧跟数字("11 万/月"不写"110,000 元人民币每月")

## 七、逻辑结构

- **SCQA**:情境(Situation)→冲突(Complication)→问题(Question)→答案(Answer)——开场与路演主线
- **金字塔**:结论先行,以上统下,归类分组,逻辑递进——汇报正文
- 每章一页过渡页(section),回显目录并高亮当前位置
- 说服链:数据→解释→含义(so what),每页回答"所以呢"

## 八、动画与切换

- 原则:动画传达结构,不炫技;全 deck 一种切换(建议"淡出/推移")
- 进入动画用于分步揭示论证链(逐点出现),数据图表用"擦除"自左向右
- 时长 0.3–0.5s;全 deck 统一;打印/导出 PDF 时动画全部可丢失不损内容

## 九、图表之外的图示

- 流程:编号步骤链(圆角矩形+箭头),≤5 步一行,多了换行分组
- 架构:框+连接线,分层排布;连线只走水平/垂直/45°
- 对比矩阵:行列双向对比表,焦点格用 ACCENT 高亮
- 关系图:中心辐射(一核多因)、维恩(交集)、象限(两维定位)
- 一切图示原生绘制(形状+连接线),继承配色,不用贴图

## 十、封面设计

- 大字标题(44–72pt)+ 一句副标题点主张;深底(三明治头)
- 可选:全幅图+遮罩 / 半幅分割 / 纯排版(超大字+留白)
- 封面必须回答:讲什么、谁讲的、什么场合(日期/会议名小字)

## 十一、目录与导航

- 目录页编号 + 短语(不用"第1章"长句);当前章节高亮用浅色底带,不用色条
- 章节 section 页深底+大号编号,建立呼吸节奏

## 十二、结尾页

- 回收主张:一句话总结 + 行动请求(决策/资源/时间表)
- 联系方式小字;感谢语简短("谢谢"即可,不写华丽排比)

## 十三、母题与一致性

- 全 deck 一个签名母题:圆角图片框 / 超大数字 / 统一卡片处理(三选一)
- 边距、间距、字号、色值全部常量化,逐页引用
- 连续页检查:版式交替,色彩不跳变,母题每页在场

## 十四、速检清单(交付前 60 秒)

- [ ] 每页有唯一焦点;无纯文字页;无溢出/重叠
- [ ] 无色条/标题下划线/居中正文/emoji
- [ ] 配色三角色全程一致;图表原生;数字有来源
- [ ] 字体显式设置;CJK 无细字重;最小字号 ≥12pt
- [ ] 图片无拉伸;文字压图有遮罩;灰度测试通过
- [ ] 封面三要素齐;目录可导航;结尾有行动请求
